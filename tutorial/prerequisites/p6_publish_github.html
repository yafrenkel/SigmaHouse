🚀 Bonus — Save Your Work to GitHub

Real developers save their code to GitHub every day — so it's safe forever, shareable with a link, and never lost. You'll set this up on Tuesday morning (about 15 minutes, one time, with a grown-up), then publish your Monday work. After that it's a quick 2-minute habit: each morning, save what you built the day before. Do this and you're officially working like a pro. 😎

🧑‍🤝‍🧑 Do this one with a grown-up — you'll make an account together, and it only takes about 15 minutes to set up the first time.

🧠 Two words to know

  • Commit = save a snapshot of your work, with a little note about what you changed. Like taking a labeled photo of your progress: "added my number game."
  • Push = upload your snapshots to GitHub (the internet). Like posting your photo album online so it's safe and shareable.

So the whole loop is: make changes → commit (with a note) → push. That's it — that's what devs do all day.

🪜 Step 1 — Get a GitHub account

  1. With your grown-up, go to github.com and click Sign up.
  2. Pick a fun username (this is your coder name!), use an email your grown-up is OK with, and set a password.
✅ You have a home on the internet for your code.

🪜 Step 2 — Install GitHub Desktop

This is a friendly app that does all the git magic with buttons — no scary typing.

  1. Go to desktop.github.com and click Download.
  2. Install it, open it, and sign in with the account you just made.
✅ Your tool is ready.

🪜 Step 3 — Make a repository (your project folder)

A repository ("repo") is just a folder that GitHub keeps track of.

  1. In GitHub Desktop: File → New repository…
  2. Name it something like my-code-projects.
  3. Pick where to save it (your codeweek folder is perfect). Click Create repository.
✅ You have a repo.

🪜 Step 4 — Add your work

Copy your project files into that new repo folder — your madlibs.py, mypage.html, your capstone, whatever you're proud of.

✅ Your projects are in the folder.

🪜 Step 5 — Commit (save a snapshot)

  1. Switch back to GitHub Desktop. On the left you'll see all your files listed — those are your changes.
  2. At the bottom-left, type a short Summary message, like Added my Mad Libs and my web page.
  3. Click the blue Commit to main button.

You just took a labeled snapshot of your work. 📸

✅ Your first commit — nice!

🪜 Step 6 — Push (put it online)

  1. Click Publish repository at the top (first time only).
  2. Decide: Public (anyone with the link can see it — great for showing off) or keep the "keep private" box checked. Ask your grown-up.
  3. Click Publish repository.

🎉 Your work is now on GitHub! Click View on GitHub (or the repo link) to see your very own project page on the internet.

✅ You shipped it. You have a real GitHub portfolio now — a link you can send to grandparents, friends, anyone.

🔁 Next time you make changes

The daily loop from now on:

  1. Change or add files.
  2. In GitHub Desktop: type a message → Commit to main.
  3. Click Push origin. Done!
🔗 This is the real deal: the actual smart-house camp project lives on GitHub, and everyone who works on it uses this exact commit → push loop. You just learned a skill you'll use for years. 🌍

💡 Why developers do this

  • Never lose work — it's saved online, with every version in history.
  • Time travel — you can look back at any old snapshot ("commit").
  • Share instantly — send a link instead of files.
  • Teamwork — many people can build the same project together.
▶ Too much setup? The 30-second website way

No app needed: on github.com, make a New repository, then click Add file → Upload files, drag your project files in, and click Commit changes. It's more manual (you re-drag each time), but it works great for just saving your stuff.

🏆 You now code AND publish like a professional developer. That's a huge deal — be proud!
