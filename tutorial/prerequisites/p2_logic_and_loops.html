🎯 Mission 1 — True, False, and comparisons

Every decision a computer makes comes down to one thing: is something True or False? Those two values are called booleans. Comparisons produce them:

print(5 > 3)        # True
print(10 == 10)     # True   (== means "equal to")
print(7 != 7)       # False  (!= means "not equal")
print("cat" == "dog")   # False

Comparisons: > < >= <= == (equal) != (not equal).

🔮 Predict first, then run. Before typing these into Thonny, write down what each will print: 
print(3 < 3)
print(3 <= 3)
print(100 != 99)
print("Sam" == "sam")
▶ Answers

False (3 is not less than 3), True (3 is less-than-or-equal to 3), True, False (capital S ≠ small s — computers are picky about that!).

✅ Win: you understand the True/False values every decision is built on.

🎯 Mission 2 — Combine conditions: and, or, not

Real decisions need more than one test. Combine them:

  • and — True only if both sides are True.
  • or — True if either side is True.
  • not — flips True↔False.
age = 14
tall_enough = True

print(age >= 13 and age <= 19)   # is it a teenager? True
print(age < 13 or age > 65)      # kid or senior? False
print(not tall_enough)           # False

🛠 Try it — the rollercoaster checker: a rider must be at least 120 cm tall AND at least 10 years old. Ask for their height and age, then print whether they can ride.

▶ Peek 
height = int(input("Height in cm? "))
age = int(input("Age? "))

if height >= 120 and age >= 10:
    print("🎢 You can ride!")
else:
    print("Sorry, not yet.")
✅ Win: you can build decisions with multiple rules — like real programs do.

🎯 Mission 3 — Branching paths, and paths inside paths

You know if / elif / else. Now stack them and nest them. Here's an outfit advisor:

temp = int(input("Temperature? "))
raining = input("Is it raining? (yes/no) ")

if temp > 25:
    print("👕 T-shirt weather!")
elif temp > 15:
    print("🧥 Light jacket.")
else:
    print("🧣 Bundle up, it's cold.")

# a SECOND, separate decision — notice the indent puts the umbrella INSIDE the if
if raining == "yes":
    print("☂️ ...and take an umbrella!")

🛠 Try it: extend it — if the temperature is above 30, also remind them to "drink water 💧". (Add another if.)

✅ Win: you can make layered decisions.

🎯 Mission 4 — The % trick + a famous puzzle (FizzBuzz)

The modulo operator % gives the remainder after division. It's secretly one of the most useful tools in coding:

print(10 % 3)      # 1  (10 ÷ 3 = 3 remainder 1)
print(12 % 4)      # 0  (divides evenly!)
print(7 % 2)       # 1  (odd number)
print(8 % 2)       # 0  (even number)

💡 Big idea: n % 2 == 0 means "n is even". n % 5 == 0 means "n divides by 5". This unlocks a classic.

🧩 FizzBuzz — real companies ask this in job interviews! Loop through the numbers 1 to 20 and print:
  • the number normally, BUT
  • if it divides by 3 → print "Fizz" instead
  • if it divides by 5 → print "Buzz" instead
  • if it divides by BOTH 3 and 5 → print "FizzBuzz"

🛠 Try it yourself first — this is a real brain-bender. Hint: check the "both" case first. Wrestle with it for a good 10 minutes before peeking. You can do this!

▶ Peek (only after you've really tried!) 
for n in range(1, 21):
    if n % 3 == 0 and n % 5 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)

Why check "both" first? Because 15 divides by 3 and 5 — if you checked n % 3 first, you'd print "Fizz" and never reach "FizzBuzz". Order matters!

✅ Win: you solved a real interview puzzle. That's a legit brag. 🏆

🎯 Mission 5 — Loops that count and add (the accumulator)

A super-common pattern: keep a running total that grows each time through the loop.

total = 0
for n in range(1, 6):     # 1, 2, 3, 4, 5
    total = total + n     # add each number to the total
    print(f"added {n}, total is now {total}")

print("Grand total:", total)    # 15

🛠 Try it: add up all the even numbers from 1 to 20. (Combine an accumulator with the % 2 == 0 even-check from Mission 4.)

▶ Peek 
total = 0
for n in range(1, 21):
    if n % 2 == 0:
        total = total + n
print("Sum of evens 1-20:", total)   # 110
✅ Win: you can make a loop build up a result — the engine behind scores, totals, and counters.

🎯 Mission 6 — break and continue (steering a loop)

  • break — jump out of the loop right now.
  • continue — skip the rest of this turn, go straight to the next one.
for n in range(1, 11):
    if n == 7:
        print("Found 7 — stopping!")
        break              # leave the loop entirely
    if n % 2 == 0:
        continue           # skip even numbers
    print(n)               # only prints 1, 3, 5

🛠 Try it: loop from 1 to 100, but break as soon as you hit the first number that divides by both 6 and 8. (What number is it?)

✅ Win: you can steer a loop, not just ride it.

🎯 Mission 7 — Loops inside loops 🤯

You can put a loop inside another loop. The inner one runs fully for each step of the outer one. This is a real step up — read it slowly.

for row in range(1, 4):        # outer: 1, 2, 3
    for col in range(1, 4):    # inner: runs 1,2,3 each time
        print(f"{row}-{col}", end="  ")
    print()                    # new line after each row

That prints a little grid. 🛠 Try it — a star triangle: print this shape using a loop inside a loop:

*
**
***
****
*****

Hint: for row 1 print 1 star, row 2 print 2 stars… The trick "*" * row makes a string of that many stars.

▶ Peek 
for row in range(1, 6):
    print("*" * row)

# ...or the long way, with a nested loop:
for row in range(1, 6):
    for star in range(row):
        print("*", end="")
    print()
✅ Win: nested loops — one of the trickiest beginner ideas, and you've got it.

👑 Boss Build — Rock, Paper, Scissors vs. the Computer

Build a full game: you vs. the computer, first to 3 wins. It pulls together everything today — while, if/elif/else, and/or, and counters.

🛠 Build it up in pieces. First get one round working (computer picks, you pick, decide who won). Then wrap it in a while loop that keeps score until someone reaches 3.

▶ Peek (the full game — try to build it before looking!) 
import random

options = ["rock", "paper", "scissors"]
you = 0
computer = 0

print("🪨📄✂️  Rock-Paper-Scissors! First to 3 wins.")

while you < 3 and computer < 3:
    your_move = input("\nrock, paper, or scissors? ")
    comp_move = random.choice(options)
    print("Computer chose:", comp_move)

    if your_move == comp_move:
        print("Tie!")
    elif (your_move == "rock" and comp_move == "scissors") or (your_move == "paper" and comp_move == "rock") or (your_move == "scissors" and comp_move == "paper"):
        print("You win this round! 🎉")
        you = you + 1
    else:
        print("Computer wins this round. 🤖")
        computer = computer + 1

    print(f"Score — You: {you}, Computer: {computer}")

if you == 3:
    print("\n🏆 YOU WIN THE GAME!")
else:
    print("\n🤖 Computer wins the game. Rematch?")
✅ 👑 Boss done — a real game! Play it against a family member (take turns being "you"). Log it, collect your bonus. 💵

🐞 Debug Challenge (a real dev skill)

This code is supposed to print the numbers 1 to 5 — but it runs forever! 😱 Find the bug and fix it. (Press the red Stop button in Thonny to escape the runaway loop.) 
n = 1
while n <= 5:
    print(n)
▶ What's wrong? (think first!)

The loop never changes n, so n <= 5 is always True — it prints 1 forever. The fix is to add a line that increases n each time:

n = 1
while n <= 5:
    print(n)
    n = n + 1        # <-- the missing line!

💡 "It runs forever" almost always means a while loop whose condition never becomes False. Always ask: "what makes this loop stop?"

✅ Win: you debugged an infinite loop — a rite of passage for every coder.
