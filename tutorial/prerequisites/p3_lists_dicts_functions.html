🎯 Mission 1 — Lists, deeper

A list holds many values in order, inside [ ]. You've met .append() — here's the rest of the toolkit:

scores = [40, 90, 75, 60, 90]

print(scores[0])        # 40   — first (counting starts at 0)
print(scores[-1])       # 90   — last (negative counts from the end!)
print(len(scores))      # 5    — how many
print(max(scores))      # 90   — biggest
print(min(scores))      # 40   — smallest
print(sum(scores))      # 355  — total
print(sorted(scores))   # [40, 60, 75, 90, 90] — a sorted copy
print(90 in scores)     # True — is 90 somewhere in the list?

scores.append(100)      # add to the end
scores.remove(40)       # remove the first 40
print(scores)

Slicing — grab a piece of a list

letters = ["a", "b", "c", "d", "e"]
print(letters[1:3])     # ['b', 'c']  — from index 1 up to (not including) 3
print(letters[:2])      # ['a', 'b']  — the first two
print(letters[-2:])     # ['d', 'e']  — the last two
🔮 Predict, then run. For nums = [10, 20, 30, 40, 50]: 
print(nums[2])
print(nums[-1])
print(nums[1:4])
print(sum(nums) / len(nums))
▶ Answers

30 · 50 · [20, 30, 40] · 30.0 (that last one is the average — sum divided by how many!).

🛠 Try it: make a list of 6 test scores. Print the highest, the lowest, and the average. Then print just the last three scores using a slice.

✅ Win: you can slice, sort, search, and summarize a list.

🎯 Mission 2 — Dictionaries, deeper (and dicts inside dicts)

A dictionary stores key → value pairs in { }. New powers:

device = {"name": "lamp", "on": False, "brightness": 80}

print(device["name"])          # lamp
print(device.get("color", "unknown"))   # safe lookup: "unknown" if no such key
print("on" in device)          # True — is there an "on" key?

# loop over BOTH keys and values:
for key, value in device.items():
    print(f"{key} = {value}")

The big one: a dictionary of dictionaries

This is exactly how the real smart-house hub stores every house. Read it slowly:

houses = {
    "house_A": {"led": True,  "fan": False},
    "house_B": {"led": False, "fan": True},
}

print(houses["house_A"]["led"])    # True — dig in two levels
houses["house_B"]["fan"] = False   # change a nested value

for name, state in houses.items():
    print(f"{name}: LED={state['led']}, fan={state['fan']}")
🔗 This IS the project. The real hub keeps a dictionary of houses, each with its own state dictionary. You're not learning a toy version — you're learning the actual data structure the smart house runs on. 🤯

🛠 Try it: make a dictionary of 3 friends, where each value is a dictionary with their age and favorite_color. Then loop and print "Sam is 13 and loves blue" for each.

🎯 Mission 3 — Functions that work together

A function packages code you can reuse. Today: functions with defaults, and functions that call other functions.

def greet(name, greeting="Hello"):     # greeting has a DEFAULT value
    return f"{greeting}, {name}!"

print(greet("Sam"))                    # Hello, Sam!   (uses the default)
print(greet("Sam", "Yo"))              # Yo, Sam!      (overrides it)

def is_even(n):
    return n % 2 == 0                  # returns True or False

def describe(n):
    if is_even(n):                     # one function calling another
        return f"{n} is even"
    else:
        return f"{n} is odd"

print(describe(4))     # 4 is even
print(describe(7))     # 7 is odd

🛠 Try it: write a function average(numbers) that takes a list and returns its average. Then use it: print(average([10, 20, 30])) should give 20.0.

▶ Peek 
def average(numbers):
    return sum(numbers) / len(numbers)

print(average([10, 20, 30]))   # 20.0
print(average([5, 5, 5, 5]))   # 5.0
✅ Win: you can build functions that team up — the way real programs are organized.

🐞 Debug Challenge

This should print each fruit with its number, but it crashes with an error. Find and fix it. 
fruits = ["apple", "banana", "cherry"]
for i in range(1, 4):
    print(i, fruits[i])
▶ What's wrong?

List positions start at 0, so valid indexes are 0, 1, 2. But range(1, 4) gives 1, 2, 3 — and fruits[3] doesn't exist → IndexError: list index out of range. Fix it by starting at 0:

fruits = ["apple", "banana", "cherry"]
for i in range(len(fruits)):      # 0, 1, 2
    print(i, fruits[i])

💡 IndexError almost always means you counted past the end of a list. Off-by-one bugs are the most common bug in all of programming — now you'll spot them.

✅ Win: you can squash an off-by-one bug — a pro-level catch.

👑 Boss Build — A real smart-house controller

Yesterday's tools + today's = a genuinely capable smart house. Build a house with rooms, each room holding devices, controlled by typed commands. This is a simplified version of the actual camp hub.

🛠 Build it in stages. Stage 1: the data + a show() that prints every room and device. Stage 2: a command loop that understands on, off, and status.

house = {
    "living_room": {"led": False, "fan": False},
    "bedroom":     {"led": False, "buzzer": False},
}

def show(house):
    print("\n=== HOUSE STATUS ===")
    for room, devices in house.items():
        print(f"[{room}]")
        for name, on in devices.items():
            print(f"   {name}: {'ON' if on else 'off'}")

def set_device(house, room, device, value):
    if room in house and device in house[room]:
        house[room][device] = value
        print(f"  → {room}/{device} set to {'ON' if value else 'off'}")
    else:
        print("  ! No such room/device")

# quick test:
show(house)
set_device(house, "bedroom", "led", True)
show(house)

Now the interactive command loop — type things like living_room led on:

while True:
    command = input("\nCommand (room device on/off, or 'quit'): ")
    if command == "quit":
        break
    parts = command.split()          # splits "living_room led on" into a list
    if len(parts) == 3:
        room, device, action = parts
        set_device(house, room, device, action == "on")
        show(house)
    else:
        print("  ! Try: living_room led on")
