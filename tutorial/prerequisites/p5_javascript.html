🎯 Mission 1 — JavaScript basics

JavaScript lives in a <script> tag. It's a cousin of Python — here are the differences at a glance:

PythonJavaScript
name = "Sam"let name = "Sam";
print(x)console.log(x);
def f():function f() { }
indentation{ } curly braces
<script>
  let name = "Junior Developer";
  let age = 13;
  console.log("Hi " + name);        // combine text with +
  console.log(`Next year: ${age + 1}`);   // template string (like an f-string!)
</script>

🛠 Try it: put that in a page, open it, press F12 → Console to see the messages. Change the name and refresh. (let = a variable that can change; const = one that can't.)

✅ Win: you can read and write JavaScript — you already know most of it from Python!

🎯 Mission 2 — A button that runs your code

<h1 id="title">Click the button!</h1>
<button onclick="surprise()">Surprise me</button>

<script>
  function surprise() {
    document.getElementById("title").textContent = "You clicked me! 🎉";
  }
</script>
  • onclick="surprise()" — run this function when clicked.
  • document.getElementById("title") — grab the element with id="title".
  • .textContent = "..." — change its text.

🛠 Try it: add a second button that resets the heading to its original text.

✅ Win: a click that changes the screen — the heartbeat of every app.

🎯 Mission 3 — Arrays & loops in JavaScript

JavaScript's version of a list is an array. Loops look a little different but do the same job:

let fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]);        // apple
console.log(fruits.length);    // 3

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

let pick = Math.floor(Math.random() * fruits.length);   // random index
console.log("Random fruit: " + fruits[pick]);

🛠 Try it: make an array of 4 compliments. Write a function cheer() that picks a random one and shows it in an <h1>. Wire it to a button.

🎯 Mission 4 — Change styles with JavaScript

JS can change how things look, not just their text. The magic move for dashboards is classList.toggle — it adds a CSS class if it's missing, removes it if it's there.

<style> .on { background: #c8f7c5; } </style>

<div id="box">Click me</div>
<script>
  function flip() {
    document.getElementById("box").classList.toggle("on");
  }
</script>
<button onclick="flip()">Toggle</button>

🛠 Try it: make the box turn green when you click, and back when you click again.

✅ Win: you can change styles on the fly — exactly how a dashboard shows a device turning on.

🐞 Debug Challenge

This button should change the heading, but clicking does nothing (and the Console shows an error). Find the bug. 
<h1 id="title">Hello</h1>
<button onclick="change()">Change</button>
<script>
  function change() {
    document.getElementById("titel").textContent = "Changed!";
  }
</script>
▶ What's wrong?

"titel" is a typo — the element's id is "title". getElementById("titel") finds nothing (null), so setting .textContent on it throws an error (check the F12 Console — it'll say "Cannot set properties of null"). Fix the spelling to "title".

💡 When a button "does nothing," open the Console (F12) — the error almost always names the exact problem.

✅ Win: you can use the Console to hunt down a JavaScript bug — a real pro habit.

👑 Boss Build — Your dashboard COMES ALIVE

Take yesterday's smart-house dashboard mockup and make the cards actually clickable — click a device to toggle it ON/off, changing both its color and its label. This is a real interactive dashboard. 🤯

▶ Peek (a full working dashboard — build yours, peek if stuck) 
<!doctype html>
<html>
<head><style>
  body { font-family: Arial; background: #f4f6f8; }
  .bar { background: #0b6b4f; color: white; padding: 16px; border-radius: 8px;
         text-align: center; font-size: 22px; }
  .row { display: flex; gap: 14px; margin-top: 16px; }
  .card { flex: 1; padding: 24px; border-radius: 10px; text-align: center;
          font-size: 20px; border: 2px solid #ccc; background: #eee; color: #888;
          cursor: pointer; }
  .card.on { background: #c8f7c5; border-color: #57cc99; color: #1f2328; }
</style></head>
<body>
  <div class="bar">🏠 My Smart House</div>
  <div class="row">
    <div class="card" onclick="toggle(this, '💡 LED')">💡 LED<br><span>off</span></div>
    <div class="card" onclick="toggle(this, '🌀 Fan')">🌀 Fan<br><span>off</span></div>
    <div class="card" onclick="toggle(this, '🔔 Buzzer')">🔔 Buzzer<br><span>off</span></div>
  </div>

  <script>
    function toggle(card, label) {
      card.classList.toggle("on");                       // flip the color
      let isOn = card.classList.contains("on");
      card.querySelector("span").textContent = isOn ? "ON" : "off";   // flip the text
    }
  </script>
</body>
</html>

New tricks: this = "the card you clicked", card.querySelector("span") = find the label inside it, and condition ? "ON" : "off" = a quick if/else (called a ternary).

🔗 You just built the real thing. The actual camp dashboard works exactly like this — click a device, its card flips color and label. You've built the front end of an IoT system! 🎉

🚀 The Real Deal — control an actual smart house (with a grown-up)

One more JavaScript power runs the real dashboard: fetch — it asks a server for data without reloading the page. Time to use it for real.

Ask your manager to start the smart-house hub on the laptop. Open the dashboard page, press F12 → Console, and paste:

await fetch("/api/houses", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ unique_id: "DEV1", ip_address: "127.0.0.1" })
}).then(r => r.json())

Refresh the dashboard — a house named DEV1 appears! You registered a real house on a real IoT system using JavaScript you now understand. 🤯 (Hub not set up yet? No worries — you'll do this on Day 1 of camp.)

✅ Win: you connected everything you learned to a real live system.
