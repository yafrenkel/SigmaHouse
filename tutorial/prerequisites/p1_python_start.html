🐙 First: meet GitHub (where this came from)

You're reading this because it was shared on GitHub — a website where programmers store and share their code. Think of it like Google Drive, but for code projects. (The real smart-house camp project lives on GitHub too!)

How to grab a project from GitHub — a real skill you'll use again and again:

  1. Open the project's GitHub page in your browser (your manager will give you the link).
  2. Click the green <> Code button near the top-right.
  3. Click Download ZIP.
  4. Find the downloaded ZIP (usually in your Downloads folder), right-click it → Extract All… to unzip it.
  5. Open the unzipped folder and double-click index.html — that's your Code Week home page. 🎉

That's it — you now know how to download almost any open project on the internet. Real coders do this every day. 🌍 (Already reading this? Then you've basically done it — nice work! 😊)

🎯 Mission 1 — Make the computer talk

See how text goes in quotes, but numbers don't? Try changing the words and running again.

✅ Win: you made the computer print your own message.

🎯 Mission 2 — Remember things (variables)

A variable is a labeled box that stores a value so you can use it later.

name = "Ada"
age = 13
print("Hi", name)
print("Next year you'll be", age + 1)

Even cleaner — an f-string lets you drop variables right into text with { }:

print(f"Hi {name}, you are {age} years old.")

🛠 Try it: make variables for your name, age, and favorite_food, then print one sentence using all three with an f-string.

▶ Peek 
name = "Junior Developer"
age = 13
favorite_food = "sushi"
print(f"I'm {name}, I'm {age}, and I love {favorite_food}.")
✅ Win: you stored and used your own info.

🎯 Mission 3 — Ask the human (input)

input(...) stops and waits for you to type an answer, then hands it back.

name = input("What's your name? ")
print(f"Nice to meet you, {name}!")

🛠 Try it: ask for the person's name AND their favorite animal, then print a fun sentence with both.

✅ Win: your program has a conversation now.

🎯 Mission 4 — Numbers vs. text (a sneaky gotcha)

Big rule: input() always gives you text, even if you type a number. Text can't do math! To do math, convert it with int() (whole number) first.

age = input("How old are you? ")
age = int(age)                 # turn the text "13" into the number 13
print(f"In 10 years you'll be {age + 10}.")

🛠 Try it: run it. Then delete the int() line and run again — you'll get a red error, because text + number doesn't work. That error is a normal part of coding! Put the line back.

▶ Why did it break?

Without int(), age is the text "13", and Python won't add the number 10 to text. int() converts it to a real number. (Reading error messages is a superpower — the last line usually names the problem.)

✅ Win: you learned the #1 beginner gotcha before it ever confused you.

👑 Boss Build — Mad-Libs story generator

Mad Libs: ask for a few random words, then drop them into a silly story. Ask for at least a name, an adjective (describing word, like "smelly"), a verb (action, like "danced"), and an animal. Then print a funny 2–3 sentence story using all of them.

🛠 Build it — start from this and finish the story your way:

name = input("A name: ")
adjective = input("A describing word: ")
verb = input("An action word (past tense): ")
animal = input("An animal: ")

print()
print(f"One day, {name} met a {adjective} {animal}.")
print(f"Together they {verb} all the way to the moon!")
# add 1-2 more silly lines of your own
▶ Peek (one full version) 
name = input("A name: ")
adjective = input("A describing word: ")
verb = input("An action word (past tense): ")
animal = input("An animal: ")
place = input("A place: ")

print()
print(f"One sunny morning, {name} woke up next to a {adjective} {animal}.")
print(f"They {verb} together all the way to {place}.")
print(f"And that is how {name} became famous. The end. 🎉")
✅ 👑 Boss done! Run it for a family member with their words — get a laugh. Log it and collect your Boss bonus. 💵
