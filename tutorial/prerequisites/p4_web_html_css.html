Thursday — The Web: HTML & CSS 🌐

Today you leave Python and learn to build web pages — the exact skills behind the smart-house dashboard. HTML is the structure; CSS is the style. By the end you'll build a real dashboard mockup.

☀️ First: commit yesterday's smart-house controller to GitHub. Then let's build the web.

🛠 Setup — editor + browser + DevTools

Open Notepad to write HTML. Save files with "Save as type" → All Files, named like mypage.html, into your codeweek folder, then double-click to open in the browser. The loop is: edit → save → refresh (F5).

🔎 Meet DevTools: in the browser, press F12 → the Elements tab. You can see the page's HTML and even change styles live. Every web developer lives in here.

🎯 Mission 1 — Structure with the right tags

HTML = tags in angle brackets, mostly in pairs. Beyond headings and paragraphs, these organize a page:

<!doctype html>
<html>
<body>
  <h1>My Page</h1>

  <div>
    <h2>A section</h2>
    <p>A <span>span</span> wraps a few words; a <strong>div</strong> wraps a whole block.</p>
  </div>

  <a href="https://wikipedia.org" target="_blank">A link (opens in a new tab)</a>
  <img src="cat.jpg" alt="my cat" width="200">
</body>
</html>

<div> = a box that groups things. <span> = a small inline wrapper. target="_blank" opens a link in a new tab. alt describes an image (for screen readers and when it won't load).

🛠 Try it: build a page with two <div> sections, each with its own <h2> and paragraph.

✅ Win: you can structure a page into sections.

🎯 Mission 2 — CSS with classes

Yesterday you styled tags (h1 { ... }). Real sites use classes so you can style specific things. Add class="..." in the HTML, and target it with a dot . in the CSS:

<head>
  <style>
    .card {
      background: white;
      border: 2px solid #4cc9f0;
      border-radius: 10px;
      padding: 16px;
      margin: 10px;
    }
    .warning { color: red; font-weight: bold; }
  </style>
</head>
<body>
  <div class="card">I'm a styled card! 🎴</div>
  <p class="warning">This text is red and bold.</p>
</body>

🛠 Try it: make a .card class and use it on three different <div>s. Change one thing (like the border color) in the CSS and watch all three update at once — that's the power of classes.

✅ Win: you can style specific elements and reuse styles.

🎯 Mission 3 — The box model (space around things)

Every element is a box with three layers of space. Getting this right is 80% of making a page look good:

  • padding — space inside the box, between the border and the content.
  • border — the edge line.
  • margin — space outside the box, pushing other things away.
.box {
  padding: 20px;         /* breathing room inside */
  border: 3px solid navy;
  margin: 15px;          /* gap outside */
  background: #eef;
}

🛠 Try it: make a .box, then in DevTools (F12) hover over it — the browser highlights padding (green) and margin (orange) so you can see the box model. Change the padding number and watch the inside grow.

✅ Win: you can control spacing like a designer.

🎯 Mission 4 — Layout with Flexbox (things side by side)

By default, boxes stack vertically. To place them in a row, put them in a container with display: flex. This is how dashboards lay out their cards.

<head><style>
  .row { display: flex; gap: 12px; }
  .tile {
    background: #d5e8d4; padding: 20px; border-radius: 8px;
    flex: 1;                 /* each tile shares the space equally */
    text-align: center;
  }
</style></head>
<body>
  <div class="row">
    <div class="tile">💡 LED</div>
    <div class="tile">🌀 Fan</div>
    <div class="tile">🔔 Buzzer</div>
  </div>
</body>

🛠 Try it: make a row of 3 tiles. Then remove display: flex and refresh — see them stack? Put it back. That one line is the whole trick.

✅ Win: you can lay out a page in rows — real layout skills.

🎯 Mission 5 — Hover effects (a taste of interactivity)

The :hover rule changes an element when the mouse is over it:

.tile:hover {
  background: #ffd23f;
  cursor: pointer;
}

🛠 Try it: add a hover effect to your tiles so they change color when you point at them.

✅ Win: your page reacts to the mouse.

🐞 Debug Challenge

This page's heading is supposed to be purple, but it stays black. Why? 
<head>
  <style>
    h1 { colour: purple; }
  </style>
</head>
<body>
  <h1>Hello</h1>
</body>
▶ What's wrong?

It's color, not colour (CSS uses American spelling). The browser silently ignores properties it doesn't recognize — no error, it just does nothing. Fix: h1 { color: purple; }.

💡 When a style "doesn't work," check for a typo in the property name or a missing ; or } first. DevTools (F12 → Elements) will show your rule with a ⚠️ if it's invalid.

✅ Win: you learned the sneakiest CSS gotcha there is.

👑 Boss Build — A Smart-House Dashboard mockup

Build a static (not-yet-clickable) dashboard that looks like the real thing — a title bar and a row of device cards showing ON/off. Tomorrow you'll make it actually work with JavaScript!

Requirements:

  • A styled title bar at the top (a <div> with a background color).
  • A flex row of at least 3 device cards (LED, Fan, Buzzer).
  • Use a class like .on (green) vs .off (gray) so some show ON and some off.
  • A hover effect on the cards.
▶ Peek (a full starter — then make it your own) 
<!doctype html>
<html>
<head><style>
  body { font-family: Arial; background: #f4f6f8; }
  .bar { background: #0b6b4f; color: white; padding: 16px; border-radius: 8px;
         font-size: 22px; text-align: center; }
  .row { display: flex; gap: 14px; margin-top: 16px; }
  .card { flex: 1; padding: 24px; border-radius: 10px; text-align: center;
          font-size: 20px; border: 2px solid #ccc; }
  .card:hover { transform: scale(1.03); cursor: pointer; }
  .on  { background: #c8f7c5; border-color: #57cc99; }
  .off { background: #eeeeee; color: #888; }
</style></head>
<body>
  <div class="bar">🏠 My Smart House</div>
  <div class="row">
    <div class="card on">💡 LED<br>ON</div>
    <div class="card off">🌀 Fan<br>off</div>
    <div class="card on">🔔 Buzzer<br>ON</div>
  </div>
</body>
</html>
🔗 This looks a LOT like the real camp dashboard — a header and colored device cards. You're building the front end of a real IoT system!
✅ 👑 Boss done! Show your dashboard in the browser. Log it, collect your bonus. 💵
