# 👩‍💻 Code Week — Your Coding Apprenticeship

Welcome, **Junior Developer**! 👋

This is a **5-day, self-guided coding week** that takes you from zero to building real things — Python programs *and* interactive web pages. It's fun, it's paid 💵, and by Friday you'll control a real internet-connected smart house.

## 🚀 How to start (2 minutes)

1. Click the green **`<> Code`** button near the top-right of this page.
2. Click **Download ZIP**.
3. Find the downloaded ZIP (usually in your **Downloads** folder), right-click it → **Extract All…** to unzip it.
4. Open the unzipped folder and **double-click `index.html`**.

That opens your **home base** — your schedule, your missions, and how you get paid. Start there! 🎉

## 💡 The one rule

Type the code yourself (don't copy-paste), and when you're stuck, use the **▶ Peek** button built into every puzzle — that's your hint. Google and AI are off-limits for the answers, because the whole point is to grow *your* brain. 💪
