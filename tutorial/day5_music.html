🎵 Bonus — Buzzer music, solo to orchestra

The buzzer isn't only for the alarm — it can play tunes. This bonus goes from one board playing a melody all the way to a room full of boards playing a round together. All offline: just the buzzer (GPIO 4) and button A. (How the buzzer turns a frequency into a pitch is in the Circuits page.)

All the files live in examples/bonus_music/.

Part 1 — Play a melody

🛠 Try this: upload play_melody.py to the board and run it. You'll hear a scale, then "Ode to Joy".

A tune is just a list of (note, beats) pairs. buzzer.freq(hz) sets the pitch; buzzer.duty(512) sets the volume. A frequency of 0 means a rest (silence).

💡 Scroll to YOUR TURN at the bottom of the file and write your own tune.

Part 2 — Pick from 16 tunes

🛠 Try this: upload melodies_options.py too (16 ready-made tunes). In play_melody.py set CHOICE near the top to a number 1–16 and re-run — or 0 to hear them all.

Part 3 — An "orchestra" on ONE board

A single buzzer can only make one pitch at a time, but orchestra.py fakes a two-part sound two ways: it either flips between two notes so fast they blend into a chord, or — if you wire a second buzzer to GPIO 5 — plays a real harmony a octave below. Flip TWO_BUZZERS = True for the real thing.

Part 4 — Ensemble: 3–4 boards play together 🎻

Now the fun one. Give every board one voice of the same song and they harmonise as a group. The easy, great-sounding way is a round (a canon): every board plays the same melody, but each one starts a few beats after the last. Frère Jacques is a real 4-part round — made for exactly this.

💡 Why a round is the easy path: real 4-part harmony means writing four different lines by hand. A round needs none of that — it's one melody, just entered at different times, and it's musically guaranteed to fit. It also forgives sloppy timing: the delays are baked into each board, so it's fine if you don't all press "GO" at the exact same instant.

Set it up

  1. Upload both orchestra_ensemble.py and melodies_options.py to every board.
  2. Set the same song / arrangement / tempo on all boards (see the card).
  3. Give each board a different VOICE number: 1, 2, 3, 4.
  4. Run it on every board. Everyone holds button A; someone counts "3–2–1–GO" and you all press together.

🎫 Setup cheat-sheet — 4-board Frère Jacques round

Same on EVERY board (top of orchestra_ensemble.py):

SONG        = songs.FRERE_JACQUES
ARRANGEMENT = "round"
ROUND_DELAY = 8
TEMPO_MS    = 400

Different on each board — just this one line:

BOARD 1
VOICE = 1
BOARD 2
VOICE = 2
BOARD 3
VOICE = 3
BOARD 4
VOICE = 4

Only 3 boards? Use cards 1–3 and drop VOICE = 4. Voice 1 leads; each next voice folds in ROUND_DELAY (8) beats later.

✅ Milestone: press together — voice 1 starts, the others stack in one after another into a round.

Which songs work best

ArrangementBest songsBoards
"round" — canon (the easy path)Frère Jacques (4-part!), Row Row Row Your Boat2, 3, 4+
"octave" — voices stacked in octavesTwinkle, Ode to Joy, When the Saints2–3

To switch to octave mode, set ARRANGEMENT = "octave" on every board — then voice 1 plays the melody, voice 2 an octave lower, voice 3 an octave higher, voice 4 two lower.

⚡ Stretch — tighter sync: in octave mode you might hear a faint echo if your starts aren't together. Fix it with a wire: join a GND pin on each board, and run an output pin on the "conductor" board to an input pin on the others — the conductor raises it to say "GO". Ask a counsellor.
