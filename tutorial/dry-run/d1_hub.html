🐞 Snags to watch for (and the fixes)

▶ The dashboard won't load / it opened on the wrong address

Run the hub as a plain script: open implementation/iot_hub/app.py in PyCharm and use Run ▶ (or a terminal: python app.py). Don't use PyCharm's "Flask server" button — that launches it on the wrong port/address. Our hub runs itself on http://localhost:8080.

▶ Make sure you're running the RIGHT hub

Use implementation/iot_hub/app.py. There's an older hub elsewhere in the project — ignore it. If routes look weird, check the file path.

▶ curl in PowerShell gives quoting errors

PowerShell's curl is not real curl and mangles JSON. Easiest for Part 3: open the dashboard, press F12 → Console, and use a fetch(...) like the field guide shows. (Or use Git Bash, or Invoke-RestMethod.)

▶ "Failed to fetch" / CORS error in the console

The hub now sends the header that allows this, so just make sure you restarted the hub after any change (Ctrl-C, then run it again). If you opened your test page as a file://, that's fine — the hub allows it.
